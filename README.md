# Backend Engineering Mastery

Long-term, 29-phase Backend Engineering Mastery program. This repository is the single source of truth for curriculum documents, progress tracking, engineering decisions, conceptual notes, and verified labs.

## Collaboration Model

- **GitHub Repository:** Source of truth for all program artifacts.
- **ChatGPT (Curriculum Owner & Instructor):** Owns the approved 29-phase roadmap, phase order, scope, schedule, allocated hours, mastery assessment, and final phase approval.
- **Learner:** Drives study, reasoning, experimentation, implementation, and mastery demonstration.
- **Antigravity (Research & Engineering Partner):** Assists with mechanism-level research, reproducible experiments, and engineering reviews under the constraints in [AGENTS.md](./AGENTS.md).

## Core Documents

- [MASTER_ROADMAP.md](./MASTER_ROADMAP.md) — Authoritative 29-phase curriculum (ChatGPT-owned).
- [LEARNING_JOURNEY.md](./LEARNING_JOURNEY.md) — High-level connected progression, concept dependencies, and seams across all 29 phases.
- [PROGRESS.md](./PROGRESS.md) — Phase and block status tracking (`planned`, `in progress`, `completed`, `approved`).
- [NEXT_SESSION.md](./NEXT_SESSION.md) — Exact session-to-session learning continuity.
- [LEARNING_PHILOSOPHY.md](./LEARNING_PHILOSOPHY.md) — Core engineering, study, and guided-discovery teaching principles.
- [BACKEND_KNOWLEDGE_INDEX.md](./BACKEND_KNOWLEDGE_INDEX.md) — Cross-phase relational index of concepts, prerequisites, mechanisms, alternatives, trade-offs, and required depth.
- [DECISIONS.md](./DECISIONS.md) — Log of repository and program workflow decisions.

## Workspace Configuration

- **Rules:** [AGENTS.md](./AGENTS.md) and `.agents/rules/` (`learning-standards.md`, `research-standards.md`, `github-safety.md`).
- **Reusable Agent Skills:** `.agents/skills/` (`phase-kickoff`, `teaching-material-design`, `mechanism-deep-dive`, `lab-experiment`, `code-and-design-review`, `phase-checkpoint-handoff`).
- **Phases:** `phases/` — created strictly one phase at a time as each phase is unlocked.
