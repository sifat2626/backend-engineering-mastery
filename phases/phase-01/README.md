## Approved Mastery Outcomes (10)

The learner should be able to:

1. Explain the difference between programming and software engineering.
2. Analyze a request before implementation.
3. Identify assumptions, ambiguities, and missing requirements.
4. Define correctness and meaningful software quality.
5. Identify engineering constraints.
6. Compare alternatives and explain trade-offs.
7. Distinguish evidence from opinion.
8. Recognize unnecessary complexity and overengineering.
9. Use AI as an engineering partner while independently verifying its output.
10. Take responsibility for technical decisions and their consequences.
